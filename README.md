# Последний сигнал

**Играть: https://eclipseinc.github.io/astrogame/**

Изометрическая лунная игра на Three.js. Маленький космонавт Луми собирает три
энергоячейки и возвращает связь станции «Кратер-7», пока не кончился кислород.
Полное прохождение — 3–4 минуты.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Продакшен-сборка публикуется на GitHub Pages автоматически при push в `main`
(`.github/workflows/deploy.yml`).

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD / стрелки | движение (относительно камеры) |
| Space | прыжок (удержание = выше) |
| Q / E | поворот камеры на 90° |
| F | фонарь |
| M | карта (клик — метка, клик по метке — убрать, Esc — закрыть) |

Звук включается кнопкой «ЗВУК» в правом нижнем углу, выбор запоминается.

Подбор ячеек, баллонов и установка в антенну — автоматически по касанию.

```

  core/input.js        клавиатура, justPressed / held

  world/lighting.js    солнце, тени, рассвет финала
  world/props.js       валуны, станция, ровер, ступени кратера, гряда, колонны
  world/items.js       энергоячейки и кислородные баллоны
  world/sky.js         звёзды и Земля (отдельная сцена)
  player/player.js     модель, физика, анимация, маркер приземления, силуэт
```

## Три решения, на которых держится изометрия + платформинг

Изометрия плохо сочетается с прыжками: не видно, куда приземлишься, и объекты
заслоняют героя. В проекте это закрыто тремя механиками:

1. **Маркер приземления** — кольцо на поверхности строго под игроком
   (`player.js`, `updateMarker`). В полёте он ярче и крупнее.
2. **Поворот камеры на 90°** (Q/E) — обязательная механика, а не удобство.
3. **Силуэт сквозь препятствия** — уменьшенная копия космонавта рисуется с
   `depthTest: false` перед основной моделью. Если герой не перекрыт, его тело
   закрашивает силуэт; если перекрыт — силуэт видно сквозь камень.

Плюс сама лунная гравитация: прыжок длинный, есть время скорректировать
траекторию в воздухе.

## Дальность прыжка (для левел-дизайна)

Прыжок дозируется удержанием Space, и это главный параметр при расстановке
платформ:

| Как прыгать | Дальность | Время в воздухе | Высота |
| --- | --- | --- | --- |
| короткое нажатие | 5.8 м | 1.25 с | 1.95 м |
| Space зажат | 9.2 м | 1.9 с | 2.93 м |

Разбег почти ничего не добавляет (9.45 м против 9.18 м): в полёте скорость
всё равно набирается за счёт управления в воздухе. Поэтому узкие колонны, с
которых не разогнаться, — честная площадка для прыжка.

Проходимость курса проверяется скриптом `tools/checks/course.mjs`: для каждой
пары платформ он перебирает длительность удержания и считает, при скольких
кадрах прыжок попадает. Окно меньше 6 кадров (0.1 с) считается слишком узким.

## Что заложено под расширение

- **Точки интереса** — массивы `CELL_SPOTS` и `CANISTER_SPOTS` в `game/game.js`.
  Добавить ячейку = дописать строку, HUD и логика подхватят сами.
- **Кратеры** — массив `CRATERS` в `world/terrain.js`, рельеф пересчитается.
- **Ровер** лежит разбитый у старта — крючок под механику транспорта.
- **Рассвет** (`lighting.setDawn`) уже параметризован от 0 до 1 — отсюда легко
  вырастает полный суточный цикл.
- **Кислород** — по сути валюта: под неё просятся апгрейды скафандра.

## Звук

Ни одного аудиофайла: всё синтезируется на Web Audio при загрузке. Логика
звука идёт от физики — на Луне нет воздуха, поэтому слышно только то, что
доходит до ушей внутри скафандра. Шаги задавлены фильтром низких частот,
рация трещит несущей перед каждой репликой, дыхание учащается по мере
расхода кислорода, а под конец добавляется пульс.

## Известные ограничения

- Прогресс не сохраняется между сессиями: рестарт начинает забег заново.
- Коллизии — круглые тела с плоским верхом, габариты берутся из bounding box.
  Произвольная геометрия не поддерживается: на остроконечном камне стоишь на
  невидимом плоском пятачке чуть уже силуэта.
- Метки на карте живут до перезагрузки страницы, но переживают рестарт забега.
- Тени накрывают область ±58 м вокруг игрока; дальше объекты рисуются без теней.
- `world/sky.js` (звёзды и Земля) написан, но в изометрии не виден: камера
  смотрит вниз, поверхность закрывает весь кадр. Модуль ждёт катсцены или
  низкого ракурса — рендерится отдельной сценой и стоит почти ничего.
